# Next.js Exploration with gql.tada 🪄

In short, `gql.tada` + `urql` + NEXT JS App Router,

## Setup

1. Install dependencies:
```bash
pnpm install
```

2. Run the development server:
```bash
pnpm dev
```

3. Open [http://localhost:6596](http://localhost:6596) in your browser

## Important Notes

- ⚠️ **Caution**: Make sure your editor is using the same typescript version as the repo for gql.tada to work properly

## Features

- Pokemon card gallery with images
- Search functionality
- Infinite scroll pagination
- Download Pokemon cards as PNG
- Dark theme UI
- Comprehensive Pokemon detail pages
